# InPASS + GI Registry + PPV&FR Registry — Free DB guide

- InPASS (https://ipindia.gov.in/inpass.htm): free patent search.
- GI Registry (Chennai): https://search.ipindia.gov.in/GIRPublic/
- PPV&FR: https://plantauthority.gov.in/
- Paid DBs (Derwent, Orbit): access only with explicit logged consent per PS. This system never hits paid DB unless user toggles allow_paid_db + consent_id.
